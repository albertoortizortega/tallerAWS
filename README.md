# Tarea: Servir un Sitio Estático desde S3

Este repositorio contiene los archivos y la documentación para la tarea de desplegar un sitio web estático utilizando Amazon S3

## Descripción

El objetivo de esta tarea es demostrar la capacidad de alojar y servir un sitio web estático utilizando Amazon Simple Storage Service (S3) de AWS

## Contenido del Repositorio

- Archivo index.html
- Documento con capturas

## Pasos para Desplegar el Sitio Web con Amazon S3

1.  *Creación de un Bucket S3*

2.  *Carga de los Archivos del Sitio Web: index.html*

3.  *Configuración de Permisos (Política de Bucket)*

4.  *Configuración del Alojamiento de Sitios Web Estáticos*

5.  *Acceso al Sitio Web usando el endpoint de sitio web del bucket*
